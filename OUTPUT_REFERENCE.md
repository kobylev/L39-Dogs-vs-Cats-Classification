# Output Files Reference

This document describes the files that will be generated in the `output/` directory when you run `python main.py`.

---

## File Generation Timeline

```
python main.py
├── Step 1: Download & Prepare (5-15 min)
│   └── Creates: data/raw/, data/data_summary.json
│
├── Step 2: Data Split (< 1 min)
│   └── Creates: data/train/, data/val/
│
├── Step 3: Training (1-30 min depending on device)
│   ├── Generates: output/model.pth
│   └── Generates: output/training_curves.png
│
└── Step 4: Evaluation (< 1 min)
    ├── Generates: output/confusion_matrix.png
    ├── Generates: output/sample_predictions.png
    └── Generates: output/classification_report.txt
```

## 1. model.pth (Trained Model Weights)

**Type:** Binary PyTorch checkpoint file
**Size:** ~160 MB
**Format:** PyTorch state_dict

### What It Contains
- All learned weights and biases from the trained CNN
- Serialized model parameters (no architecture info)

### How to Use It Later
```python
import torch
from src.model import CatDogCNN

# Load the trained model
model = CatDogCNN()
model.load_state_dict(torch.load('output/model.pth'))
model.eval()

# Make predictions on new images
with torch.no_grad():
    prediction = model(new_image_tensor)
    probability = torch.sigmoid(prediction).item()
    label = "Dog" if probability > 0.5 else "Cat"
```

### Storage Note
- Can be excluded from version control (add to .gitignore if desired)
- ~160 MB, can be regenerated by retraining
- Currently kept in repo for reproducibility

## 2. training_curves.png (Training Progress Visualization)

**Type:** PNG image (300 DPI)
**Size:** ~400-600 KB
**Dimensions:** 1400×500 pixels

### Contents: Two Side-by-Side Plots

#### Left Plot: Loss Curves
```
Y-axis: Loss (lower is better)
X-axis: Epoch (0-20)

Blue line:  Training loss (calculated on 2010 train images)
Red line:   Validation loss (calculated on 990 val images)
```

**What you're looking for:**
- Both curves should trend downward
- Validation loss tracking training loss (not diverging)
- Curves should plateau around epoch 15-20

**Interpretation:**
```
Ideal:        ↘  ↘  ↘  ⟹ (loss decreases)
Overfitting:  Train ↘ much faster than Val ↗ (diverging)
Underfitting: Both plateau too early with high values
```

#### Right Plot: Accuracy Curves
```
Y-axis: Accuracy (0-1, higher is better)
X-axis: Epoch (0-20)

Blue line:  Training accuracy
Red line:   Validation accuracy
```

**What you're looking for:**
- Both curves should trend upward
- Final values around 0.85-0.92 (85-92% correct)
- Curves should flatten (diminishing returns)

### Example Interpretation

If your curves look like:
```
Loss (Left):      Starts ~0.69 → Ends ~0.25 ✓
Accuracy (Right): Starts ~0.50 → Ends ~0.88 ✓
Divergence:       Minimal ✓
```
→ **Good fit!** Model learning well without severe overfitting.

If your curves look like:
```
Loss:      Train goes to 0.1, Val stays at 0.5 ✗
Accuracy:  Train goes to 0.98, Val stays at 0.60 ✗
Divergence: Large and growing ✗
```
→ **Overfitting!** Model memorizing training data, not generalizing.

### Creating Custom Versions

You can regenerate these plots post-training:
```python
import matplotlib.pyplot as plt
from src.train import train_model

model, metrics = train_model(data_dir, output_dir)

# Replot with custom styling
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(metrics['train_losses'], label='Train')
ax.plot(metrics['val_losses'], label='Val')
ax.set_xlabel('Epoch')
ax.set_ylabel('Loss')
ax.legend()
plt.savefig('custom_loss.png')
```

## 3. confusion_matrix.png (Prediction Breakdown Heatmap)

**Type:** PNG image (300 DPI)
**Size:** ~200-400 KB
**Dimensions:** 600×500 pixels

### What It Shows

A 2×2 heatmap matrix:

```
                 Predicted Cat    Predicted Dog
Actual Cat       [count]          [count]
Actual Dog       [count]          [count]
```

### Reading the Matrix

```
Example output:
                 Predicted Cat    Predicted Dog
Actual Cat            450              45
Actual Dog             30             465
```

**Diagonal (correct):**
- (0,0): 450 cats correctly identified as cats
- (1,1): 465 dogs correctly identified as dogs
- Total correct: 450 + 465 = 915 / 990 = 92.4% accuracy

**Off-diagonal (errors):**
- (0,1): 45 cats wrongly identified as dogs
  - False negative rate for cats: 45/495 = 9.1%
- (1,0): 30 dogs wrongly identified as cats
  - False negative rate for dogs: 30/495 = 6.1%

### Heatmap Color Interpretation

- **Darker blue:** Higher count of predictions
- **Lighter blue:** Lower count
- **Numbers in cells:** Exact count

### Common Patterns

**Good fit:**
```
     Pred Cat  Pred Dog
Act Cat   90%      10%      (mostly correct, few errors)
Act Dog   10%      90%      (mostly correct, few errors)
```

**Biased toward one class:**
```
     Pred Cat  Pred Dog
Act Cat   60%      40%      (model underconfident)
Act Dog   20%      80%      (or always guesses same class)
```

**Perfectly balanced errors (symmetric):**
```
     Pred Cat  Pred Dog
Act Cat   92%       8%      (same error rate for both)
Act Dog    8%      92%      (suggests unbiased model)
```

### Calculating Metrics from Confusion Matrix

From the matrix above (450, 45, 30, 465):

**For cats (class 0):**
- Precision = 450 / (450+30) = 93.8%  (correctness when predicting cat)
- Recall = 450 / (450+45) = 90.9%     (coverage of actual cats)

**For dogs (class 1):**
- Precision = 465 / (465+45) = 91.2%  (correctness when predicting dog)
- Recall = 465 / (465+30) = 93.9%     (coverage of actual dogs)

These exact numbers appear in `classification_report.txt`.

## 4. sample_predictions.png (Example Predictions Grid)

**Type:** PNG image (300 DPI)
**Size:** ~600-900 KB
**Dimensions:** 1000×1000 pixels

### Layout

A 4×4 grid of 16 random validation images, each showing:

```
[Image 1]        [Image 2]        [Image 3]        [Image 4]
Pred: cat (0.87) Pred: dog (0.92) Pred: cat (0.91) Pred: dog (0.78)
True: cat        True: dog        True: dog        True: dog
```

### Color Coding

**Each image's title uses colored text:**

- **🟢 Green title:** Correct prediction
  ```
  Pred: dog (0.87)
  True: dog
  ✓ Matches!
  ```

- **🔴 Red title:** Incorrect prediction
  ```
  Pred: cat (0.62)
  True: dog
  ✗ Mismatch!
  ```

### Information in Each Title

For each image:
1. **Predicted label** and **confidence** (0.0-1.0)
   - 0.0 = "definitely cat"
   - 0.5 = "uncertain"
   - 1.0 = "definitely dog"
2. **True label** (what it actually is)

Example:
```
Pred: dog (0.87) — Model thinks this is a dog with 87% confidence
True: dog        — It actually is a dog ✓ Correct!
```

```
Pred: dog (0.61) — Model thinks dog but uncertain (61% vs 39% cat)
True: cat        — Actually a cat ✗ Wrong!
```

### What to Look For

1. **Pattern in errors (red titles):**
   - Are they on blurry images?
   - Unusual poses?
   - Partial crops?
   - Specific breeds?

2. **Confidence in correct predictions (green):**
   - Are confidences high (>0.9) for clear images?
   - Are they high for ambiguous images?

3. **Confidence in wrong predictions (red):**
   - Is the model very confident about errors? (concerning)
   - Is it uncertain (confidence ~0.5)? (better - model is unsure)

### Example Interpretation

```
16 samples total:
- 14 green (87.5% correct on these random samples)
- 2 red

Red sample 1: Blurry cat, predicted dog (0.58)
→ Reasonable error - image is unclear

Red sample 2: Small dog, predicted cat (0.71)
→ Model confuses small dogs with cats
→ Suggests model struggles with size/scale

Conclusion: Main weakness is size variation
→ Consider adding size augmentation in training
```

## 5. classification_report.txt (Detailed Metrics)

**Type:** Plain text file
**Size:** ~2-5 KB
**Format:** Markdown-like table with metrics

### Full Example Output

```
======================================================================
CLASSIFICATION REPORT
======================================================================

              precision    recall  f1-score   support

        cats       0.9375    0.9091    0.9231       495
        dogs       0.9118    0.9394    0.9254       495

    accuracy                           0.9242       990
   macro avg       0.9247    0.9242    0.9242       990
weighted avg       0.9247    0.9242    0.9242       990

======================================================================
Overall Validation Accuracy: 0.9242
======================================================================
```

### Metric Definitions

#### Precision
"Of all images I predicted as this class, how many were actually this class?"

```
Precision(cats) = (# correctly identified cats) / (# all images predicted as cat)
                = 450 / (450+30) = 0.9375
```

**Interpretation:**
- 93.75% of images I called "cat" were actually cats
- 6.25% were false positives (actually dogs)

#### Recall
"Of all actual images of this class, what percentage did I find?"

```
Recall(cats) = (# correctly identified cats) / (# all actual cats)
             = 450 / (450+45) = 0.9091
```

**Interpretation:**
- I found 90.91% of actual cat images
- I missed 9.09% (false negatives)

#### F1-Score
Harmonic mean of precision and recall (single score 0-1, higher is better).

```
F1 = 2 × (Precision × Recall) / (Precision + Recall)
   = 2 × (0.9375 × 0.9091) / (0.9375 + 0.9091)
   = 0.9231
```

**Why use it?** Balances precision and recall; single easy-to-compare number.

#### Support
Total number of test samples for each class.
```
Support(cats) = 495 (total cat images in validation set)
Support(dogs) = 495 (total dog images in validation set)
```

### Interpreting Scores

| Range | Meaning | Interpretation |
|-------|---------|---|
| 0.90-1.00 | Excellent | Production-ready; very few mistakes |
| 0.80-0.89 | Good | Generally reliable; acceptable for most uses |
| 0.70-0.79 | Fair | Notable errors; use with caution |
| <0.70 | Poor | Significant failures; needs improvement |

### Average Metrics

**accuracy:** Overall correctness across all classes.
```
accuracy = (# correct) / (# total)
         = (450 + 465) / 990
         = 0.9242
```

**macro avg:** Average of per-class metrics (treats classes equally).
```
macro_precision = (0.9375 + 0.9118) / 2 = 0.9247
```

**weighted avg:** Class-weighted average (accounts for class imbalance).
```
# Since both classes have 495 samples, weighted ≈ macro
```

### Use Cases for Each Metric

| Metric | Best For |
|--------|----------|
| Precision | When false positives are costly (spam filter) |
| Recall | When false negatives are costly (disease screening) |
| F1-Score | When you want balanced precision/recall |
| Accuracy | Overall correctness; most intuitive |

### Comparing Results

Save reports after different training runs:


### Parsing Programmatically

```python
import pandas as pd

# Read the report
with open('output/classification_report.txt', 'r') as f:
    content = f.read()

# Extract accuracy line
for line in content.split('\n'):
    if 'accuracy' in line and 'Overall' not in line:
        print(f"Validation Accuracy: {line}")
```
