WHAT THE PROJECT DOES
═══════════════════════════════════════════════════════════════════════════════════

Trains a CNN to classify images as either a CAT or a DOG

Pipeline:
  1. Downloads Microsoft Cats vs Dogs dataset (25,000+ images)
  2. Validates & cleans data (removes corrupt images)
  3. Creates balanced train/validation split (3000 images)
  4. Trains a 3-layer CNN for 20 epochs
  5. Evaluates on validation set
  6. Generates 4 visualizations + metrics report

Runtime: 20-40 minutes (includes data download on first run)
